Política de Privacidade

Esta política explica como o Vertice trata dados necessários para autenticação, funcionamento da aplicação e integrações autorizadas pelo usuário.

1. Dados tratados

O Vertice pode armazenar dados de conta, configurações, conteúdo inserido ou enviado, registros técnicos de segurança e informações necessárias para executar as funções escolhidas pelo usuário.

2. TikTok

Quando o usuário conecta o TikTok, o Vertice recebe somente os dados e permissões disponibilizados pela API conforme os escopos autorizados. Isso pode incluir identificador da conta, nome de exibição, avatar e tokens OAuth necessários para manter a conexão e executar ações solicitadas.

3. Instagram / Meta

Quando o usuário conecta uma conta compatível do Instagram, o Vertice recebe os dados e tokens disponibilizados pelas APIs oficiais conforme as permissões concedidas. Esses dados são usados para identificar a conta e executar ações solicitadas pelo usuário.

4. Senhas e tokens

O Vertice não solicita a senha do TikTok ou Instagram dentro da própria aplicação. O login ocorre nas páginas oficiais dos provedores. Tokens e segredos de integração são tratados pelo backend e não são exibidos integralmente ao navegador.

5. Finalidade

Os dados são utilizados para autenticação, segurança, funcionamento do produto, identificação de contas conectadas, upload e publicação de conteúdo solicitado pelo usuário e manutenção das integrações autorizadas.

6. Compartilhamento

Dados são enviados às plataformas conectadas quando necessário para executar uma ação solicitada. Cada plataforma externa também possui seus próprios termos e políticas.

7. Retenção e desconexão

A conexão social permanece armazenada enquanto for necessária ao funcionamento da integração. O usuário pode desconectar TikTok ou Instagram na área de Integrações do Vertice, removendo os tokens ativos armazenados para aquela conexão.

8. Exclusão

As instruções de exclusão estão disponíveis na página Exclusão de dados. Conteúdo já publicado em redes externas deve ser removido também pelos controles da respectiva plataforma quando necessário.

9. Hospedagem deste site

Este site informativo é hospedado pelo GitHub Pages. O repositório público não contém banco de dados do Vertice, tokens OAuth, Client Secrets ou arquivos pessoais da instalação local.

10. Contato

Solicitações relativas a este documento podem ser abertas pelo canal público de contato do projeto no GitHub.
