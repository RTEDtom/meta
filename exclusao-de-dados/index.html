Exclusão de dados

O usuário pode remover integrações sociais e, quando aplicável, excluir os dados mantidos pelo Vertice. A remoção no Vertice não exclui automaticamente conteúdo que já tenha sido publicado em uma plataforma externa.

Desconectar TikTok

No Vertice, abra Integrações → TikTok → Desconectar. A conexão é desativada e os tokens OAuth armazenados para aquela conta deixam de ser utilizados pelo Vertice.

Desconectar Instagram

No Vertice, abra Integrações → Instagram → Desconectar. A conexão é desativada e os tokens armazenados para aquela conta deixam de ser utilizados pelo Vertice.

Excluir a conta Vertice

Quando o fluxo de exclusão de conta estiver disponível para a instalação, utilize a área de Configurações e confirme sua identidade. O processo remove os dados da conta do banco ativo e os arquivos associados conforme as funções implementadas no produto.

Solicitação manual

Se não for possível acessar a conta, utilize o canal público de contato em GitHub Issues. Informe somente o necessário para identificar a solicitação. Nunca envie senha, Client Secret, access token ou refresh token.

Dados mantidos pelas plataformas

Vídeos, publicações e dados que estejam armazenados diretamente pelo TikTok ou Meta/Instagram seguem as políticas e ferramentas dessas plataformas. Para remover conteúdo já publicado, utilize também os controles da própria rede social.
