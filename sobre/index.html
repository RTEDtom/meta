Sobre o Vertice

O Vertice organiza criação, mídia, calendário e publicação de conteúdo. Contas sociais são conectadas somente após autorização do usuário nas páginas oficiais de cada plataforma.

TikTok

O Vertice utiliza OAuth/Login Kit e, quando habilitado, a Content Posting API. O usuário escolhe autorizar a conexão e as permissões apresentadas pelo TikTok.

Instagram / Meta

O Vertice utiliza as APIs oficiais da Meta para contas compatíveis. O usuário autentica e concede as permissões disponibilizadas pela plataforma antes de qualquer ação.

Controle do usuário

O usuário pode desconectar uma conta social no Vertice. Tokens de autenticação são tratados pelo backend e não são exibidos integralmente na interface.

Este site público

Este site existe para apresentar o projeto e disponibilizar documentos públicos. O painel pessoal do Vertice continua separado e não é publicado neste repositório.

Para dúvidas ou solicitações relacionadas a este site público, utilize o canal de contato no repositório GitHub do projeto.
