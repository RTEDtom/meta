Site público do Vertice

Integrações autorizadas. Controle do usuário.

O Vertice é uma ferramenta para organizar conteúdo, arquivos, calendário e publicações em contas sociais conectadas pelo próprio usuário através das APIs oficiais das plataformas.

Política de PrivacidadeTermos de Uso
T

TikTok

A conta é conectada por OAuth. O Vertice solicita apenas os escopos necessários e executa uploads ou publicações autorizadas pelo usuário quando a API e o aplicativo tiverem permissão.

I

Instagram

Contas profissionais podem ser conectadas pelas APIs oficiais da Meta. A disponibilidade de publicação depende das permissões e requisitos definidos pela plataforma.

S

Privacidade

Este repositório público não contém banco de dados, tokens, Client Secrets, arquivos privados nem o backend pessoal do Vertice.

VVERTICESite público informativo do Vertice. O painel pessoal, dados locais, tokens e credenciais não são hospedados aqui.
